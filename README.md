# markdown-cv

A curriculum vitae maintained in plain text and rendered to HTML and PDF using CSS.

I use the template designed and made available by Eliseo Papa; for more details, see the [project page](http://elipapa.github.io/markdown-cv), or the blog post on [why Eliseo switched to markdown for a CV](http://elipapa.github.io/blog/why-i-switched-to-markdown-for-my-cv.html). I am grateful to Eliseo for making this template available.
